# Healthcare-Clinic-Booking-System
Hệ thống Quản lý Đặt lịch và Hồ sơ Y tế Điện tử (Healthcare &amp; Clinic Booking System) là một nền tảng backend số hóa toàn bộ quy trình vận hành của một phòng khám quy mô vừa. Hệ thống giải quyết hai bài toán cốt lõi: giúp bệnh nhân dễ dàng đặt lịch khám trực tuyến với bác sĩ theo khung giờ và theo dõi hồ sơ khám bệnh.
